The customer-facing menu is served at `/` and is the primary interface customers use to browse available items and compose an order. Items are organized into three categories — hamburguesas, bebidas, and desayunos — and each card displays a photo, the item name, a short description, and the price in Mexican pesos (MXN). Customers add items to their cart by clicking the **+ Agregar** button on any card.

## Categories

The menu is divided into three sections. Toggle between them using the category buttons at the top of the page:

- **Hamburguesas** — Burgers and sides
- **Bebidas** — Drinks
- **Desayunos** — Breakfast items

<Tip>
Only one category is visible at a time. Click **Desayunos**, **Hamburguesas**, or **Bebidas** at the top of the page to switch between them.
</Tip>

## Out-of-stock items

When an item is unavailable, the menu updates automatically to reflect its status:

- The item card becomes semi-transparent (`opacity-50`).
- The **+ Agregar** button is hidden.
- An **Agotado** badge appears on the card.

Out-of-stock items cannot be added to the cart.

## Real-time stock sync

The menu polls the `/api/stock` endpoint every 10 seconds to keep availability up to date without requiring a page refresh. The stock check runs in the background using `setInterval`:

```javascript
setInterval(() => {
    fetch('/api/stock').then(res => res.json()).then(inv => {
        document.querySelectorAll('.btn-agregar').forEach(btn => {
            const id = btn.getAttribute('data-product-id');
            const card = btn.closest('.card');
            if (inv[id] === false) {
                btn.classList.add('d-none');
                card.classList.add('opacity-50');
            } else {
                btn.classList.remove('d-none');
                card.classList.remove('opacity-50');
            }
        });
    });
}, 10000);
```

The response from `/api/stock` is a JSON object keyed by item ID. A value of `false` means the item is out of stock; anything truthy means it is available. Card state is updated immediately after each poll.

<Note>
Stock availability is reflected in the UI automatically. You do not need to reload the page to see changes — the menu will update within 10 seconds of a stock change.
</Note>
